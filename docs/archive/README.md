# Historical documentation

This folder preserves earlier proposal and implementation snapshots for context. The archived files contain material written for earlier versions of the application and may describe features, dependencies, validation, or plans that are no longer current.

Use the root [README](../../README.md) and the current [documentation index](../README.md) as the source of truth for present behavior. In particular, archived descriptions of AI garment analysis, Edge Functions, NativeWind, launch milestones, and early patch validation are not current implementation contracts.

Archived documents:

- `PRODUCT_PROPOSAL.md` — early product concept and positioning.
- `PATCH_NOTES.md` — notes from earlier implementation snapshots.
- `FRONTEND_IMPLEMENTATION.md` — prior UI-system implementation plan and notes.
- `REDESIGN.md` — earlier redesign patch description and verification notes.
- `ROADMAP.md` — proposal-era milestones.
- `ISSUE_BACKLOG.md` — proposal-era engineering backlog.

Do not use these files to make deployment, security, or feature-completeness decisions without checking current source and configuration.
