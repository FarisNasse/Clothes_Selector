# Five-Minute Proposal Demo

## 0:00–0:40 — Positioning

Open **Today**.

Key message:

> Clothes Selector is not another inspiration feed. It answers a narrower question: given everything I own, what should I wear right now?

Point out the weather/context card and the occasion selector.

## 0:40–1:30 — Recommendation

Select **Dinner**, then **Date**, and show how the recommended outfit changes.

Explain that every item shown exists in the structured wardrobe. The recommendation engine does not hallucinate products.

Tap **Another outfit** to show controlled choice rather than an infinite feed.

## 1:30–2:15 — Wardrobe intelligence

Open **Wardrobe**.

Show:

- indexed item count
- known wardrobe value
- recorded wears
- category filtering
- individual garment metadata

Explain that this database is the foundation for later cost-per-wear, wardrobe health, packing, and purchase intelligence.

## 2:15–3:35 — Ingestion

Tap **+**.

Enter a category, piece type, name, and color. Optionally take or select a photo.

Show the manual details:

- category
- subcategory
- color
- brand
- fit
- formality
- warmth

Adjust fit or dressiness to show that the user controls recommendation inputs.

Save the garment and return to the wardrobe.

## 3:35–4:20 — Personalization

Open **Style**.

Explain that the profile is multidimensional rather than a single style label. Then show the feedback loop:

**recommendation → swap → save → wear → rate**

Emphasize that an actual wear event is a stronger signal than a like.

## 4:20–5:00 — Trust and roadmap

Open **Profile**.

Show the privacy surface and explain private image storage and user-scoped data.

Close with the north-star metric:

> We do not optimize for minutes spent scrolling. We optimize for outfits people actually wear.
